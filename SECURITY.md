# Security / 安全回報

This preview is supported on Windows + Google Chrome. Keep Python, FFmpeg, Chrome, and project dependencies updated. TLS certificate verification is enabled by default; do not disable it as a routine workaround.

Do not report credentials, signed stream URLs, or personal paths in public issues. For a vulnerability with sensitive details, use GitHub's private vulnerability reporting if enabled on the repository. If it is unavailable, open an issue requesting a private contact channel without exploit details or secrets.

本預覽版以 Windows + Google Chrome 為支援目標。請更新系統與依賴，保留 TLS 憑證驗證。涉及敏感資訊的漏洞請使用倉庫若已啟用的 GitHub 私密漏洞回報；若尚未啟用，先開不含漏洞細節的 issue 詢問私下聯繫方式。不要公開帳密、簽章網址或個人路徑。
